# Movies Service Console — frontend

Моковый React-клиент для `moviesApi.yaml` и `oscarApi.yaml`. Все изменения живут в памяти браузера и сбрасываются после перезагрузки страницы.

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

## Docker

```bash
docker build -t filmoteca-frontend .
docker run --rm -p 8088:80 filmoteca-frontend
```

После запуска откройте `http://localhost:8088`.

## Сборка

```bash
npm run build
```

## Ограничения ввода

Названия фильмов и имена сценаристов ограничены 255 символами, числовой ввод — 64 символами. Перед сохранением и применением фильтров проверяются формат чисел и диапазоны типов API: бюджет до `2147483647`, локация Y от `-2147483648` до `2147483647`, локация X в диапазоне Java `float`. Для Оскаров и локации Z клиент принимает только безопасные целые JavaScript (по модулю до `9007199254740991`), чтобы при отправке JSON не терять точность. Миллионы и миллиарды допустимы, если укладываются в диапазон поля.

Длинные названия в таблице сокращаются с полным значением в подсказке; числовые значения и раскрытые подробности не расширяют колонки.

Проверка граничных значений и переполнения:

```bash
npm test
```
